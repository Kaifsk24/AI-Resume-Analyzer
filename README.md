AI Resume Analyzer

An AI-powered resume analysis application built with Python and Streamlit.

The application analyzes PDF resumes, extracts technical skills, evaluates resume quality, compares resumes with job descriptions, identifies missing skills, and provides improvement suggestions.

Features

• PDF resume upload and text extraction
• Technical skill detection
• Resume scoring
• Job description matching
• Matching and missing skill identification
• Resume improvement suggestions
• Simple and interactive Streamlit interface

Tech Stack

Python · Streamlit · PDF Processing

Project Structure

app.py
Main Streamlit application and user interface.

analyzer.py
Handles skill detection, resume scoring, job matching, and suggestions.

resume_parser.py
Extracts text from uploaded PDF resumes.

requirements.txt
Contains the required Python dependencies.

How It Works

Upload a PDF resume → Extract resume text → Detect skills → Generate resume score → Compare with job description → Identify missing skills → Generate improvement suggestions

Purpose

This project was developed to practice Python, text processing, Streamlit application development, and building practical AI-powered tools for career and recruitment workflows.
